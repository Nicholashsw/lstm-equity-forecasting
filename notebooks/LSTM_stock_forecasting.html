Deep Learning Based Stock Price Forecasting Using LSTM Networks¶

Regime-dependent cross-sectional predictability in US equities¶

This notebook is the reproducible logic flow for the project. It benchmarks an LSTM against classical machine learning for daily US equity return forecasting, then reframes the task cross-sectionally and analyses where (and whether) any signal is economically real.

Pipeline

Bloomberg export (.bas)  ─┐
                          ├─►  canonical parquet  ─►  feature panel  ─►  models  ─►  evaluation
yfinance/FRED mirror  ────┘     (source-agnostic)      (no lookahead)     (11+LSTM)   (IC, L/S, costs)

Headline findings

  1. Daily return level prediction is a null result for every model, LSTM included.
  2. A cross-sectional reformulation reveals significant predictability that concentrates in high-volatility regimes and is stronger for nonlinear models.
  3. The effect is a one-day phenomenon: it survives neither transaction costs at daily frequency nor the move to a weekly horizon.

Licensed Bloomberg data is never committed. Set SOURCE = "yfinance" below to regenerate an open mirror with an identical schema, or point at pre-built parquets in data/processed/.

2. Feature engineering and the supervised panel¶

Every feature uses information available at the close of day $t$; the target is the next-day log return. We build both a level target and a cross-sectional target (next-day return demeaned across the universe each day), plus daily percentile-rank features for the cross-sectional task. Splits are strictly chronological.

3. Stage V1/V2: the daily-level horse race¶

Eleven model families predict next-day return levels. The naive-zero baseline is the anchor. A shuffled-target run is included as a leakage alarm: a non-trivial IC there would mean the pipeline leaks.

In [5]:
def daily_ic(df, pcol="y_pred", tcol="y_true"):
    ic = (df.groupby("date")
            .apply(lambda g: stats.spearmanr(g[pcol], g[tcol])[0]
                   if g[pcol].nunique() > 1 and len(g) > 4 else np.nan,
                   include_groups=False).dropna())
    t = ic.mean() / (ic.std() / np.sqrt(len(ic))) if len(ic) > 2 else np.nan
    return ic, ic.mean(), t

5. Horizon and cost analysis: is it tradeable?¶

Two independent reality checks. (a) Transaction costs: 10 bps/side on one-way turnover. (b) Horizon: retarget to 5-day returns and rebalance weekly with non-overlapping observations (cuts trading frequency ~5x).

Reading it. The gross high-vol Sharpe (LightGBM 2.09) looks strong, but:

  • Costs kill the daily version. ~2.6 one-way daily turnover ≈ 26 bps/day of cost, more than the edge, so every net Sharpe is negative.
  • The signal decays. At a 5-day horizon the high-vol IC collapses to ≈ 0 ($-0.007$) and the tree model degenerates to near-constant predictions. Slowing down removes the cost and the signal.

So the effect is a genuine but short-horizon, stress-concentrated, non-tradeable phenomenon, consistent with short-term reversal / liquidity provision.

6. Conclusion¶

  1. Daily return-level prediction is a null result across 11 models incl. LSTM.
  2. Cross-sectional predictability is real and significant, concentrated in high-volatility regimes, stronger for nonlinear models.
  3. It is a one-day effect that survives neither costs (daily) nor time (weekly).

A precisely characterised negative result, with leakage controls, chronological evaluation and explicit cost accounting, is more credible than an unaudited backtest that appears to succeed.

Extensions (see docs/): point-in-time membership to remove survivorship bias; turnover-controlled execution; geographic replication (KOSPI/TAIEX/EM) as a robustness test of the regime effect; slower fundamental signals.
