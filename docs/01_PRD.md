# PRD: LSTM Stock Forecasting System

## Problem
UROP requires a defensible empirical comparison of deep learning (LSTM) vs classical ML for daily equity return forecasting, with clean data lineage from Bloomberg and full reproducibility on a personal laptop (no terminal dependency after export).

## Users
- Primary: Nicholas (research, iteration, report writing)
- Secondary: UROP supervisor (needs to audit methodology and reproduce results)

## Functional requirements
FR1. Ingest Bloomberg BDH CSV exports produced by `mod_BBG_UROP_Export.bas` (block layout: row5 ticker, row6 field, row8+ data, 3-col blocks).
FR2. Ingest yfinance mirror with identical output schema for off-terminal development.
FR3. Build leakage-safe supervised panel: features at close(t), target = log return close(t)->close(t+1).
FR4. Train and evaluate >= 10 models incl. LSTM on identical splits.
FR5. Emit machine-readable results (CSV) and publication-quality figures (PNG).
FR6. Single entrypoint `run_all.py` with `--source {yfinance,bloomberg}` and `--stage {v1a,v1b}` flags.

## Non-functional requirements
NFR1. Full V1A run < 30 min on laptop CPU.
NFR2. Deterministic: seeded numpy/torch, pinned split dates.
NFR3. No network needed when `--source bloomberg` (offline reproducibility).
NFR4. Every intermediate artifact on disk (raw parquet -> panel parquet -> results CSV) so any step can be audited in isolation.

## Explicit non-goals (core scope)
- No intraday data. No live trading. No hyperparameter search beyond a small documented grid. No survivorship correction in core (see extension E4).

## Success metrics
- Reproducibility: two runs, identical results CSV (hash match).
- Scientific: honest test-set comparison; directional accuracy and daily IC reported with the naive baseline anchoring the table.
- Deliverable: final report figures generated by code, zero manual chart edits.

## Risks
| Risk | Mitigation |
|---|---|
| Bloomberg export delayed | yfinance mirror keeps modeling unblocked; schemas identical |
| LSTM underperforms linear models (common on daily returns) | Framed as valid finding; regime-conditional extension gives LSTM its best shot |
| Lookahead bug inflates results | Leakage rules in 00_MASTER_PLAN; H6 includes a shuffled-target sanity test |
| yfinance/Bloomberg price discrepancies | Parity check script compares overlapping tickers, tolerance report in appendix |
